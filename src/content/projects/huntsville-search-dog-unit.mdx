A professional website for the Huntsville Search Dog Unit, a local search and rescue dog team serving the Huntsville, Alabama area. This project showcases modern web development practices while providing essential information and contact capabilities for emergency services.

## Project Overview

The website serves as a comprehensive information hub for the Huntsville Search Dog Unit, allowing visitors to learn about the team's mission, capabilities, and how to request their services. The site includes detailed information about what the team does, their location, and multiple ways to get in touch.

## Key Features

- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Contact Form**: Integrated email contact form for easy communication
- **Information Pages**: Detailed sections about the team's services and capabilities
- **Location Information**: Clear contact details and service area information
- **Professional Presentation**: Clean, professional design that builds trust

## Technical Stack

- **Frontend**: Next.js with React for a modern, performant user experience
- **Styling**: Tailwind CSS for rapid, responsive design development
- **Deployment**: Docker containerization for consistent deployment
- **Web Server**: Caddy for reverse proxy and automatic HTTPS
- **Email Integration**: Server-side email handling for contact form submissions

## Development Process

The project was built using modern development practices, including:

- Component-based architecture with React
- Responsive design principles with Tailwind CSS
- Containerized deployment with Docker
- Automated HTTPS and reverse proxy with Caddy

This website demonstrates the ability to create professional, functional web applications that serve real community needs while utilizing current web technologies and deployment strategies.
